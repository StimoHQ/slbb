# Описание проекта:
- **Название**: Simple Language Barrier Breaker.
- **Суть**: Платформа для изучения английского языка через чтение контента. Пользователь читает контент, добавляет незнакомые слова в личный словарь, а система организует их интервальное повторение с помощью автоматических напоминаний.
- **Стадия**: MVP. Основной источник книг — бесплатные тексты из Project Gutenberg.
- **Реализуемая часть проекта:** Backend
## Core Functionality (MVP)
1.  **Источник книг**: Интеграция с Project Gutenberg (https://www.gutenberg.org/) для поиска и загрузки текстов книг. Например 
   https://www.gutenberg.org/cache/epub/79501/pg79501.txt
2.  **Языки**: Английский для изучения, Русский как основной язык пользователя. Поэтому, прежде чем скачивать полный текст, необходимо удостовериться, что текст контента на английском языке.
3.  **Интервальное повторение**: Автоматическая система напоминаний, которая планирует показ слов для повторения на основе алгоритма интервального повторения (например, SM-2).
4.  **Уведомления**: Автоматические напоминания пользователю о необходимости повторить слова (механизм пока не определен. Можно посылать уведомления в логи сервера).

## Текущая Схема базы данных
Находится в prisma/prisma.schema 
Core models:
- **User**: User accounts
- **Text**: Book/article metadata (title, language, source)
- **TextContent**: Large text content (separate table for performance)
- **LexicalUnit**: Extracted words/phrases
- **LexicalUnitOccurrence**: Contextual occurrences in texts
- **UserLexicalUnit**: User's study status, notes, and progress tracking
